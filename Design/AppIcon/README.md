# 正式应用图标

## 当前采用方案（v6）

- 采用 X 的黑白配色：黑色圆角方形底板、白色 X。
- X 使用官方品牌工具包中的原始矢量路径；路径数据不作修改，只进行等比例缩放和居中。
- 文章元素仅保留三条白色横线。
- 三条横线位于 X 左上斜臂内部的黑色镂空区域，不放在底板左上角，也不覆盖或改变 X 的白色外轮廓。
- 圆角方形外保留真实 Alpha 透明通道。
- 黑色圆角底板沿用 v5 的尺寸和约 65 px Alpha 安全边距。
- 白色 X 与三条文章横线围绕画布中心等比缩小到 v5 的 86%；X 占黑色底板的比例由约 80% 降到约 69%，使其位置和留白接近 X 原版应用图标。

## 制作方式

本版属于已有 SVG 标志的确定性矢量组合，不使用生成模型重画标志：

1. 从 X 官方品牌工具包取得原始 X SVG 路径。
2. 在 `AppIcon-corrected-v6.svg` 中原样保留该路径；底板沿用 v5，只对 X 与文章横线整体居中缩放。
3. 将三条独立白色横线放入 X 左上斜臂的黑色内镂空，并保持小尺寸下的原有线宽观感。
4. 输出 1024×1024 PNG，再生成 macOS 标准 iconset 和 ICNS。

## 资产

- `AppIcon-corrected-v6.svg`：可编辑矢量终稿。
- `AppIcon-corrected-v6-preview.png`：1024×1024 设计终稿。
- `../../Config/AppIcon-1024.png`：安装使用的 1024×1024 母图。
- `../../Config/AppIcon.iconset/`：macOS 标准 16–1024 px 尺寸。
- `../../Config/AppIcon.icns`：应用包使用的最终图标文件。
- `../../scripts/make-app-icon.sh`：可重复的等比例转换、尺寸生成和 ICNS 打包流程。

旧版设计文件保留在本目录中，仅用于版本对照，不参与当前构建。
