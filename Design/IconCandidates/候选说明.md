# X 长文归档器·图标候选

生成方式：Codex 内置 `imagegen`。  
当前状态：仅用于选型，尚未接入应用。用户选定后，再进行 Alpha 边缘、16/32 px 可读性和 `.icns` 转换。

## 01：极简负形·X 文章

- 方向：两条交叉纸带直接构成 X。
- 文章语义：左上折角 + 三条段落线。
- 配色：深石墨底、暖白纸带、钴蓝折角。
- 特点：成熟、稳定、最像 macOS 生产力软件。

## 02：蓝底折纸·X 文章

- 方向：一条连续折纸纸带交叉成 X。
- 文章语义：右上支带三条文字切口。
- 配色：高饱和钴蓝底、白色纸带、少量黑色折面。
- 特点：年轻、鲜明、品牌识别度高。

## 03：编辑印章·X 文章

- 方向：以文章纸张为主体，在底部以负形切出 X。
- 文章语义：折角、三条正文、红色书签。
- 配色：暖白底、炭黑纸张、朱红书签。
- 特点：直接、编辑感强，归档语义清晰。

## 04：档案卡片·隐形 X

- 方向：用档案卡上的对角分割线构成隐形 X。
- 文章语义：三条段落线 + 底部归档卡槽。
- 配色：深海军蓝底、奶油白卡片、少量酸橙黄。
- 特点：概念感强，更像“归档工具”，X 需要第二眼才能看到。

## 共同提示词约束

- 用途为 macOS 应用图标。
- 必须将 X 与文章/档案结构融合成一个图形。
- 中心构图、安全边距足够、在 16 px 仍可识别。
- 不直接复制 X/Twitter 官方标志。
- 禁止鸟、聊天气泡、通知红点、水印、设备样机和多余文字。
- 用户选定前不修改应用和安装包。
